Rule format

Native rules are TOML files. Each action fixes one executable and constrains each argument by position. There are no globs.

[[action]]
id = "xudo.svc.lifecycle"
tier = "svc-control"
exe = "/usr/bin/systemctl"
args = [
  { name = "no-pager", matcher = { literal = "--no-pager" } },
  { name = "no-ask", matcher = { literal = "--no-ask-password" } },
  { name = "verb", matcher = { one-of = ["start", "stop", "restart", "try-restart", "reload", "reload-or-restart", "try-reload-or-restart"] } },
  { name = "unit", matcher = { name = "unit-name" } },
]

This example is from rules/20-services.toml. See the repository's shipped rule files and behavior source.
