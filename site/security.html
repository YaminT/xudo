Security

Beta. Not externally audited. Do not deploy where compromise would have unacceptable consequences.

The package installs only the password-authenticated gate rule. Passwordless harness execution is off until an operator enrolls a service harness, grants it an exact rule, and runs sudo xudo install --agent-path on sudo or sudo-rs. OpenDoas does not support this opt-in path. The session way is parsed and loaded but has no start command. It shares the human's uid: at ptrace_scope=0, that uid can read a typed password, xudo watch accepts a same-uid watcher on another tty, and the registry can name the human's account. Run harnesses as separate service accounts. --raise-ptrace-scope takes effect after sudo sysctl --system or reboot.

Limits

  • Authorization depends on root-owned rules and registry state, kernel-attested membership in a live root-created service scope, and checks by both broker and gate. Names and environment values are audit hints only.
  • The deny-list is defense in depth, not a complete list of programs that can become a root shell. Broad rules can grant broad root access.
  • The service account's file and network access is a host responsibility. xudo does not confine code inside the account with Landlock.
  • path-under is lexical and does not enforce filesystem containment. The separate remove-path operation has ownership checks and bounded tree traversal.
  • xudo governs only commands routed through xudo. Other host paths to root remain. xudo doctor reports paths it can inspect but cannot prove that none exist.
  • The hash-chained audit log and journal records provide tamper evidence, not protection against a malicious root user or an external trust anchor. Hints include bounded, caller-controlled argv[0], argument count, and length; they include no later arguments or digest. A process can rewrite its title, and a failed read is unavailable.

Supported package targets are Debian 13, Ubuntu 24.04 and 26.04, amd64 and arm64. See SECURITY.md for details.

Report a vulnerability

Open a private security advisory. Do not open a public issue for an exploitable vulnerability.
