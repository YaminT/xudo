xudo

sudo for AI harnesses. xudo checks each privileged command and its exact arguments against rules written by root. A verified harness may run an allowed command without a password after the operator explicitly enables the agent path. A request needing a person waits in ido for a separate reviewer. A denied command never runs.

Beta; not externally audited. Read the security limits before using it.

Install

For Debian 13, Ubuntu 24.04 or 26.04, amd64 or arm64. Download the .deb, checksum file, and signature bundle from a GitHub Release. Follow the checksum and signature verification steps in howiwork.md, then install:

sudo apt install ./xudo_<ver>_<arch>.deb

The package installs no passwordless rule. The agent path is off by default; enabling it requires a service harness, a matching rule, and the explicit sudo xudo install --agent-path opt-in on sudo or sudo-rs.

Example

xudo explain -- /usr/bin/systemctl --no-pager --full status nginx.service
xudo exec -- /usr/bin/systemctl --no-pager --full status nginx.service

explain runs nothing. A human's exec request uses the host's password prompt. An agent request follows its root-owned rule and the installed backend path.

Read how requests flow, how rules work, and the security limits. The repository's howiwork.md is the product source of truth.
