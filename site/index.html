xudo

xudo is a Linux privilege broker for operators who want AI coding agents to request narrowly defined privileged commands. It checks commands against root-owned rules and uses the host's privilege backend. This beta runs every request through the human password path.

Beta. Not externally audited. The passwordless agent path, out-of-band confirmation, and Landlock confinement are not in this release. See security status and limits.

Install

A signed Debian package on GitHub Releases, a checksum, and cosign keyless signing are planned. The package has not been released. xudo has no curl | sh installer because a privileged shell script is difficult to inspect before execution.

Example

From a checkout, --rules ./rules applies to explain. exec ignores --rules; the broker loads root's /etc/xudo/rules.d.

xudo --rules ./rules explain -- /usr/bin/systemctl --no-pager --no-ask-password restart nginx.service
xudo doctor
ido queue -m "restart nginx after review" -- /usr/bin/systemctl restart nginx.service

explain reports a decision without execution. After installing the package, add your user to the xudo group with sudo usermod -aG xudo YOUR_USER, then log out and back in. This is a deliberate privilege grant: group members can invoke the privileged gate. Then run xudo exec -- /usr/bin/systemctl --no-pager --no-ask-password restart nginx.service; it uses the host password prompt and gate.
